# Серверная часть сайта библиотеки

## Архитектура

Сервер реализует API для интеграции публичного сайта с порталом Битрикс24.

### Стек
- Node.js 20 + Express
- SQLite для кэша и состояния
- node-fetch для HTTP-запросов к Битрикс24

### Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/books` | Каталог книг из кэша |
| GET | `/api/employees` | Список сотрудников портала |
| POST | `/api/requests` | Приём заявки, создание задачи в Битрикс24 |
| GET | `/api/health` | Проверка состояния сервиса |

### Переменные окружения

```env
BITRIX_WEBHOOK_URL=https://your-portal.bitrix24.ru/rest/1/xxxxx/
ADMIN_USER_ID=1
BOT_ID=22
LOAN_DAYS=14
PORT=3000
```

### Кэширование

- Каталог книг: обновление каждые 5 минут в фоне
- Список сотрудников: обновление каждые 30 минут
- При недоступности портала отдаётся устаревший кэш

### Безопасность

- Rate limiting: 5 заявок/IP/минуту
- Валидация всех входных данных
- Вебхук только в переменных окружения
- HTTPS обязателен
- CORS: только собственный домен

### Интеграция с Битрикс24

1. **Каталог**: `crm.item.list` с `entityTypeId: 1040`
2. **Сотрудники**: `user.get` (активные пользователи)
3. **Заявка «взять»**:
   - Проверка статуса книги
   - Создание/поиск гостя в CRM 1048
   - Создание задачи согласования
   - Публикация кнопок в чат задачи через бота
4. **Заявка «вернуть»**:
   - Аналогично с типом `return`
5. **Обработка решений** (поллинг каждые 5 сек):
   - Чтение сообщений в чатах задач
   - Выполнение действий по кнопкам

### Развёртывание

```bash
npm install
npm run build
node server.js
```

Или через PM2:
```bash
pm2 start server.js --name library-site
```
